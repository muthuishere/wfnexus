# create — someone does this by hand today

## 0. Orient before you ask anything

`wf_catalog` with `kind: "shape"` and again for the names. You need to know what
skills exist before you ask what expertise the work needs — otherwise you ask
them to remember a name you could have looked up.

If a repository is in play, look at it. A workflow written without seeing the
build command is a workflow written for an imaginary project.

## 1. Interview

`references/interview.md`. Open with *"walk me through the last time you did
this by hand"*, then the four that shape the file.

## 2. Say back the shape, and STOP

Three lines: shape, stops, assumed. Then wait. Do not draft yet.

This is the moment the correction is free. After you have drafted, they will
read your YAML instead of your reasoning, and the wrong thing will survive.

## 3. Draft

Cheapest node that answers each question — `run:` before `judge:` before an
agent. Every agent step gets a soul, a scoped tool list, a budget and a real
output schema.

`steps/step-dryrun.md`.
